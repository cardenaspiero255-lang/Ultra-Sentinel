## Limitaciones de la revisión

- El inventario identifica el código y las pruebas disponibles; no autentica todos los runs, artefactos o condiciones operativas de los 13 controles.
- El observador GitHub está programado cada 30 minutos, pero se observaron huecos de varias horas. El run [42425552437](https://github.com/cardenaspiero255-lang/JARVIS/actions/runs/42425552437) informó `STALE`; un cron no garantiza vigilancia continua.
- La escritura en JARVIS #105 y un eventual rollback remoto requieren autorizaciones específicas e independientes. Una prueba local o de solo lectura no las concede.
- El planificador de calidad es declarativo: `packages/quality-gates/private-edition-readiness.cjs` no autentica por sí mismo los recibos ni autoriza release.
