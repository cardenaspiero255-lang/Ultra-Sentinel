This table describes original changes and bounded counterfactual **plans**, not a claim that every local semantic counterfactual was executed in this review.
- For Detekt `#4628/#4728/#4733/#4738`, the connected raw `expected_tests.json` reader returned empty content despite nonempty Git blob SHA; the original test names were therefore grounded in original upstream changed-test patches, **not** falsely reconstructed from the unavailable manifest. Reproduction of the full 16-task pilot remains supported by its separate SHA-indexed artifact receipts.
- Exact PR identity dedup gives nine different PRs; **independent causal fingerprint count is not established**. #4205, #4249 and #1313 were already disclosed in `C2-EIGHT-KOTLIN-UPSTREAM-ROOT-CAUSE-MATRIX-20261019.md`. #4249's two oracles are not two new causes. #2029 combines different changes/tests whose causal independence is still unknown. Cross-comparison against the 23 historical GameHub labels cannot pass until historical receipt provenance and comparable rule identities are authenticated.
- `KOTLIN_JVM_V3_EXPERIMENTAL` only permits Gradle Kotlin production paths; it does not implement Detekt's type/PSI rules, Ktlint CLI diagnostics, or Gradle Shadow's file relocation logic. **Do not build new detectors based only on these known examples.**

## Falsos positivos: measurement contract, not invented measurements

1. Before predicting, freeze specific `ruleId/path/line` and original Git base/HEAD blob for **each eligible** detector rule, and independently establish the correct safe/unsafe behavior with an executable original-source oracle.
2. For each provisional cause run original unsafe, narrowly repaired, unrelated benign, and intentionally incorrect/overbroad counterfactual; only genuine original safe cases with a detector prediction of the same rule identity can contribute to measured **FP**. One or many `p2p` JUnit outcomes cannot be multiplied into negative detector labels.
3. If there is no actual matching Sentinel rule, mark `OUT_OF_DETECTOR_SCOPE_UNSCORED` rather than TP, FN, TN or FP. Any incidental alert of a different rule needs its own independent adjudication.
4. The current nine-candidate sample has **zero independently verified matching Sentinel rule identities**, therefore `measuredFP=null`, `precision=null`, `recall=null`, `f1=null`: claiming 0 % FP or 100 % precision from this sample would be fabricated.
