# C2 Run 20 — practical original-source triage, not another fabricated label

## What is actually unblocked

The eight frozen historical GameHub PRs contain 241 changed-file occurrences, but the SHA-frozen Core is eligible for **at most 153**, excluding **88** test/Gradle occurrences. The original raw Git tree archive also contains **215 unique original HEAD Git blobs**, with **26 pairs of duplicate occurrences**. These counts concern *source snapshots*, not distinct bugs.

Instead of relabeling already repeated blobs or stopping at the unreachable "241 Core analyzed files" gate, this change adds a **deterministic work queue** of the 215 source snapshots, grouped by actual HEAD Git blob ID. It can be generated by the existing owner-only, read-only [original 15-tree workflow](../../.github/workflows/c2-run19-raw-git-trees-provenance.yml), and no detector prediction is consulted.

Run from an offline downloaded owner artifact:

\`\`\`sh
node scripts/triage-c2-original-source.cjs \
  /absolute/path/to/trees \
  /absolute/path/to/provenance_manifest.json \
  /absolute/path/to/new-original_source_triage.json
\`\`\`

The script rechecks the SHA-256 bytes of all fifteen **original** GitHub tree JSON responses, verifies the exact eight pinned historical PR base/HEAD commits, reconstructs all 241 original changed paths, detects the 26 duplicate HEAD-blob pairs, and enforces the 153/88 source-eligibility split. Any missing, modified, contradictory, unsafe or unknown entry **blocks** generation. The emitted queue rotates across PRs and prioritizes unique Core-eligible production blobs, then original test/build files; repeated blobs are one review unit.

The output always says \`UNVERIFIED_CANDIDATE_NOT_A_LABEL\`. **215 queue entries != 215 independent root causes or labels.** The queue intentionally does not read private owner label receipts or detector results, so it **does not** subtract the 18 existing owner-sealed scoped truths. Before selecting a new source oracle, cross-check those prior truths and deduplicate by root cause; if already sealed, skip.
