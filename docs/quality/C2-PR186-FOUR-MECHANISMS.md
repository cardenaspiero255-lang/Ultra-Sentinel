# C2 PR #186 — Four nonnumeric original Kotlin causal cross-probes

The historical C2 source corpus contains 12 reproducible behavior identities (6 positives/6 safe negatives). PR185 established separately the numerical repair cross effects. PR186 tests **four additional positive source mechanisms**, not model accuracy.

## Preregistered original-source factorials

Two independent Kotlin compiler/executor jobs use only SHA-pinned authentic original GameHub Kotlin sources and the existing bounded counterfactual transforms. Every JVM run is network-isolated with Bubblewrap and AppArmor, and both baseline controls run even in the original+original configuration.

| --- | --- | --- | --- |
| #152:110 JSON decoder, #158:144 research-query router | quoted `]` inside source URL no longer truncates array | current-comparison qualifier requires fresh research | Either repair must leave the other input's regression unchanged |
| #152:41 applied-profile rollback, #158:114 advanced thermal observation freshness | stale version cannot overwrite newer rollback state across interleaved packages | original signal observation age survives context refresh, while still-fresh inactive signals are retained | Either repair must leave the other subsystem's regression unchanged |

The **2×2 Kotlin test** in each pair executes 00 (both original), 01, 10, and 11 (both repaired). Each result must conform exactly to the intervention vector while passing baseline ordinary controls (two URLs without embedded closing bracket; stable comparison request; valid profile writes across packages; still-fresh idle advanced signal). Unlike counting independent-file patches, this directly distinguishes the tested local behavior effects while preserving negative controls.

The source blobs come from frozen original GitHub commit IDs. Exact Git blob SHA is checked on retrieval and execution; previously available SHA-256 original digests are also checked. Only the two attested JSON receipts and one aggregate report are archived, with no original files or runnable JARs.

## Limits

- Four positive source behaviors can have orthogonal implementation-level repair effects while belonging to broader common causal categories.
- The four new source behaviors do **not** establish four independently certified causal families or valid blind GOLD labels.
- The classification from PR184 remains provisional. No training or detector predictions are used and no benchmark statistics are inferred.
- The corpus stays **23 historical labels**, additional labels **0**, independently certified new causes **0**, blind holdout **false**, SSS+ **NOT_CERTIFIED**.
- Any failed, skipped or cancelled source/mutant job means this experiment is NOT completed.

Further causal-family adjudication still requires a frozen taxonomy, comparative oracle designs for family generalization and external-source independent detection evaluation.
