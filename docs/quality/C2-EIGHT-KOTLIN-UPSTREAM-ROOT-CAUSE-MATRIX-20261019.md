## Regla aplicable al detector: todavía no demostrada

Las rutas Kotlin experimentales de Ultra Sentinel solo permiten analizar archivos de ciertos proyectos. Ninguno de los ocho casos cuenta con un reporte acreditado de detección por el Core congelado con `ruleId`, ubicación exacta, causa raíz y controles benignos. En particular, `ForbiddenMethodCall` y `UnusedPrivateMember` son reglas **del proyecto Detekt**, no automáticamente reglas implementadas en Ultra Sentinel.

Para cada caso es obligatorio: reproducir exactamente el contrato sobre código original y control corregido, atribuirlo a una regla de Ultra Sentinel realmente existente, probar negativos cercanos, conservar hashes, verificar licencia y evitar que la corrección pública contamine el detector evaluado. Después comparar huellas de causas con las 23 etiquetas históricas autenticadas, incluidas las dependencias entre #19509/#19661.

**Decisión de admisión:** `SOURCE_PR_CAUSE_EXPLAINED_NOT_INDEPENDENTLY_CERTIFIED` para los ocho, `detectorApplicabilityVerified=false`, `historicalIndependenceVerified=false`, `newLabels=0`, `benchmarkScoredLabels=0`, `tripleSPlusCertified=false`.
