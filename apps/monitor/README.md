# Sentinel Monitor — proceso futuro independiente

Reservado para heartbeats, checks sintéticos de salud, ingesta de incidentes, alarmas y watchdog. Para vigilar 24/7 se requiere despliegue externo real y monitoreo del propio monitor; un workflow de GitHub no garantiza presencia continua.

Este directorio **no ejecuta ningún servicio**; no confundirlo con capacidad desplegada.
