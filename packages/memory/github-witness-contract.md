# GitHub and Android witness contract

`github-witness-provider.cjs` offers a read-only GitHub Contents API reader and a verifier. The reader makes a GET against the fixed `cardenaspiero255-lang/Ultra-Sentinel` repository, rejects redirects and responses larger than 20,000 bytes, and returns the raw checkpoint JSON. A host may inject an authenticated `fetch` implementation; this module does not store credentials or perform writes. Tests use simulated transports and ephemeral keys only.

The host supplies the existing journal, current owner-signed checkpoint, entries, a separately pinned owner Ed25519 public key, a separately pinned Android Ed25519 public key, a repository path, a GitHub reader and a `queryAndroid` transport. The Android transport receives a challenge containing schema, repository, path and a fresh 32-byte random nonce. It must return `{witness, signature}`, where `witness` is the device's independently retained latest owner-signed checkpoint and `signature` is canonical base64 of its Ed25519 signature over the UTF-8 bytes from `androidWitnessMessage(challenge, witness)`. That message is domain-separated and binds all checkpoint fields and the entire challenge. The device must not blindly sign a checkpoint supplied by the GitHub reader. The host must ensure a genuine independent device runs this protocol and maintains its latest state; this module does not implement or attest that behavior.

The verifier requires a fresh valid Android signature, exact agreement between the device and GitHub checkpoints, the owner's signature, and an append-only history from that checkpoint to the current journal. Missing, malformed, mismatched, replayed, forked or rolled-back evidence fails closed. The fresh nonce prevents replay of an old device response, but does not prove that the device's stored state is recent or that its storage, key, software, identity, or owner is independent or trustworthy. A live device can sign stale state. The result explicitly keeps `operationalFreshnessVerified` and `protectedOperationsAllowed` false even when signatures and prefix checks succeed. GitHub provenance, remote branch protection, merge authority, production readiness and operational custody are not established. Both keys must be pinned through an authenticated channel outside this module; no actual Android integration or remote witness has been provisioned.
