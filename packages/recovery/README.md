# Recovery / recuperación segura

Alcance: diagnósticos y recomendaciones, recuperación reversible de bajo riesgo cuando el producto permita tales acciones, propuestas RED/GREEN y rollback supervisado.

**Nada está conectado ni habilitado.** Una corrección de código en el repositorio NO reemplaza un APK instalado. No reiniciar micrófonos contra restricciones Android, no grabar audio para comprobar salud, y no desplegar releases automáticamente. La eventual ejecución de cambios necesita un autorizador confiable y un escritor externo aislado.

Relación con [issue #1](https://github.com/cardenaspiero255-lang/Ultra-Sentinel/issues/1).
